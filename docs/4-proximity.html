03 / A KERNEL WITH A VISIBLE FEATURE MAP
A sum of squares,
not a lucky eigenvalue.
Give every tree leaf its own indicator column. The all-tree collision matrix is P = ZZᵀ / T. For any real vector c, cᵀPc = Σ(tree, leaf)(Σ(rows in leaf)cᵢ)² / T ≥ 0. The identity holds for every finite forest partition, including rank-deficient matrices. This panel evaluates it exactly for six fixed training groups using integer coefficients and BigInt arithmetic.
Every leaf-bucket sum and square, exact decimal integers
2(1-Pᵢⱼ) is the squared Euclidean distance in this feature map. Distinct feature rows can share every leaf and have zero distance. Neither one-to-one identity nor useful semantic neighborhoods follow from a PSD proof.


04 / NORMALIZATION CAN CHANGE THE GEOMETRY
Three pairs.
Three different tree sets.
An exact indefinite control
Three constructed partition/eligibility tables give OOB similarities P₀₁ = 1, P₁₂ = 1, P₀₂ = 0, with diagonal 1. Every off-diagonal denominator is 1; each diagonal denominator is 2.
    1  1  0
P = 1  1  1
    0  1  1
For c = (1, -2, 1), exact cᵀPc = -2. This is a negative quadratic witness, not an approximate eigenvalue. The corresponding all-tree matrix gives 10/3 ≥ 0.
Even the triangle can fail
With dissimilarity 1-Pᵢⱼ, the same constructed OOB table gives d₀₁ = d₁₂ = 0 but d₀₂ = 1. The triangle inequality fails.
This does not say every OOB matrix is indefinite. It disproves a universal kernel or metric guarantee. No clipping, shifting, diagonal override, missing-entry fill or projection is applied to the real matrices.
The table is an original combinatorial control, not a claim that it was fitted from the historical dataset.

05 / GEOMETRY IS NOT GROUND TRUTH
Shared routes,
bounded conclusions.
The trees learned supervised class partitions. No labels are read by this new diagnostic, but the already learned partitions retain label information. Calling the computation label-free does not make the learned geometry unsupervised. Leaf IDs are meaningful only within a tree; the feature map keeps tree identity in every column.
The source-feature order and complete bootstrap multiplicities bind indexed OOB calculations. Native code recomputes the original training feature digest; the browser checks the exact exported training rows/order and recorded digest against the already hash-checked report. These are consistency checks, not authentication of arbitrary untrusted models or proofs.
No proximity-based prediction, embedding quality, data imputation, uncertainty interval or held-out score is added. Matrix display is a fixed descriptive subset, not the whole dataset. All original forest and stronger 5NN comparisons remain visible on the training page.
