01 / A SHUFFLE IS NOT AN INTERVENTION

One mapping. One intact block.

A donor is selected by a complete row bijection, not independent sampling of each column. Selected features come from the same donor row. The recipient keeps its label. Unselected features do not move. Every feature column keeps its multiset; dependencies across the block boundary can break.

04 / EVERY FEATURE BLOCK
A group is not a sum.
All 15 blocks in fixed bit-mask order, not sorted into an importance ranking. Each shows the mean and full range of its 16 error changes. Joint shuffles preserve dependence within the moved block, not across its boundary. Joint changes need not equal the sum of singleton changes. This is not an isolated interaction effect or proof of conditional importance.


05 / EXACT SUPPORT CONTROL
Same values. Impossible pairings.
Original constructed support: (0,0), (1,1), (2,2), filled green. Hollow rust points are possible one-column hybrids, outside that support. This is an original exact control, not observed UCI geometry.
Let the toy classifier return 1 exactly when the two features disagree. All three original labels are 0, so baseline error is 0.
Across all 3! = 6 row bijections, shuffling either one column gives error counts 0, 2, 2, 3, 3, 2, mean 2 out of 3. Moving both columns together gives 0 errors for every bijection.
The classifier is unchanged. Neither result establishes a causal role. The example isolates a masking/support failure in this constructed rule, not a claim that real-data blocks fix off-support evaluation.


06 / THE LIMITS BELONG WITH THE NUMBERS
Reliance under a chosen break.
The original historical UCI data, exact-copy grouping, train-derived standardization, eight forests, 19 candidate fits, all selections and original test scores are unchanged. The new diagnostic reads only validation features and labels plus the already frozen fitted models. The same 16 NumPy PCG64 row maps are used for every block and model. Fixed points are allowed. This is ordinary sampling of bijections, not derangement sampling or exhaustive 270! enumeration.
A hybrid absent from the 270 observed validation vectors is not thereby impossible. Membership in that finite support is only a descriptive count. Conversely, even the full four-feature block can preserve every observed vector and still destroy the pairing with the recipient label. Correlation, model form, score choice and reference rows all affect these diagnostics.
No feature-removal refit, conditional shuffle, causal graph, OOB permutation estimate, hypothesis test, population interval or deployment claim is supplied. The validation set has already been used for model selection. Do not choose or tune another model using this display and relabel the same data as fresh validation.
